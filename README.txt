ESP32 LoRa Secure Messenger Project
===================================

محتویات این فایل زیپ:
1. ESP32_LoRa_Messenger_Full.ino : فایل اصلی آردوینو برای آپلود روی ESP32
2. lora_crypto.h : کتابخانه اختصاصی رمزنگاری AES-128-CTR با mbedtls
3. README.txt : راهنمای راه‌اندازی

نحوه استفاده در Arduino IDE:
1. پوشه‌ای با نام EXACT: "ESP32_LoRa_Messenger_Full" ایجاد کنید.
2. دو فایل ESP32_LoRa_Messenger_Full.ino و lora_crypto.h را درون آن پوشه قرار دهید.
3. کتابخانه "LoRa" اثر Sandeep Mistry را از Library Manager نصب کنید.
4. برد را روی ESP32 Dev Module تنظیم کرده و برنامه را آپلود کنید.
